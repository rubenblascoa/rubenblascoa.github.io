Quién es el responsable

Este portfolio es personal y no tiene fines comerciales. El responsable es Rubén Blasco Armengod. Para cualquier pregunta sobre privacidad, escríbeme a rubenblascoarmengod@gmail.com.

Qué se guarda en tu navegador

Solo una cosa: si eliges idioma con el botón ES / EN, tu navegador guarda esa preferencia (localStorage, clave lang) para enseñarte la web en ese idioma la próxima vez. No sale de tu navegador, no se envía a ningún sitio y puedes borrarla cuando quieras desde los ajustes del navegador.

Estadísticas de visitas

Uso Cloudflare Web Analytics para saber cuántas visitas tiene la web y qué partes se ven más. Según Cloudflare, funciona sin cookies y sin almacenamiento en tu navegador, y no te sigue entre webs. Solo veo datos agregados: páginas vistas, país, tipo de navegador y dispositivo, de dónde llegan las visitas y tiempos de carga. Nunca sé quién eres.

Servicios que intervienen al cargar la web

Como cualquier web, al abrirla tu navegador se conecta a los servidores que la sirven, y estos reciben datos técnicos como tu dirección IP y el tipo de navegador. Las tipografías y las imágenes se sirven desde la propia web; además intervienen:

  • GitHub PagesAloja la web. GitHub registra la IP de las visitas por seguridad. Privacidad de GitHub
  • CloudflareSirve GSAP (las animaciones) desde cdnjs y la analítica descrita arriba. Privacidad de Cloudflare
  • unpkgSirve Lenis, la librería del scroll suave.
  • jsDelivrSirve Three.js, la librería del modelo 3D de la placa. Privacidad de jsDelivr

Los enlaces a otras webs (GitHub, LinkedIn, Instagram, Blasco OS, FondTracker…) llevan a sitios con su propia política de privacidad.

Por qué y durante cuánto tiempo

Las estadísticas y los datos técnicos se tratan por interés legítimo (artículo 6.1.f del RGPD): que la web funcione, sea segura y saber de forma anónima si se visita. Los correos, porque tú decides escribirme. Los correos se guardan mientras dure la conversación; los datos técnicos, lo que marque cada servicio en su política.

Tus derechos
